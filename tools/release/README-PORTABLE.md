# Veriolg MA 배포판 설치·실행 설명서

## 먼저 볼 파일

이 파일(`README-PORTABLE.md`)을 읽고, 같은 폴더의 `run_portable.cmd`를 실행하세요. `VeriolgMA.exe`는 웹 서버 본체이므로 따로 설치하지 않습니다.

## 다운로드·설치해야 할 것

| 구분 | 대상 PC에서 필요한가? | 설명 |
| --- | --- | --- |
| `VeriolgMA-portable-*.zip` | **필수 다운로드** | 배포 ZIP 하나만 복사·다운로드합니다. |
| Windows 10/11 x64 | 필수 | 이 실행 파일의 대상 운영체제입니다. |
| 웹 브라우저 | 필수 | 이미 설치된 Edge·Chrome 등으로 열면 됩니다. |
| Python, Node.js, npm | **설치 불필요** | 실행 파일과 빌드된 웹 화면에 포함됩니다. |
| WSL, Ubuntu, OpenLane, Sky130 PDK | **뷰어에는 설치 불필요** | 새 물리 설계 실행을 위한 별도 전체 개발 환경에서만 필요합니다. |

## 설치 방법

1. ZIP 파일을 대상 PC의 로컬 폴더(예: `C:\Tools\VeriolgMA`)로 복사합니다.
2. ZIP을 마우스 오른쪽 버튼으로 눌러 **모두 압축 풀기**를 선택합니다. ZIP 안에서 실행하지 마세요.
3. 압축 해제된 폴더에 `README-PORTABLE.md`, `run_portable.cmd`, `VeriolgMA.exe` 세 파일이 있는지 확인합니다. 관리자 권한·방화벽 예외는 필요하지 않습니다.

## 구동·종료 방법

1. `run_portable.cmd`를 더블클릭합니다. 서버가 시작되면 기본 브라우저가 열립니다.
2. 자동으로 열리지 않으면 브라우저 주소창에 `http://127.0.0.1:8788/`을 입력합니다.
3. 사용을 마치면 실행 중인 콘솔 창에서 `Ctrl+C`를 누르거나 창을 닫습니다.

첫 실행에는 단일 실행 파일의 압축 해제로 몇 초가 걸릴 수 있습니다. `8788` 포트를 이미 사용 중이면 서버가 시작되지 않습니다. 그 경우 콘솔에서 `VeriolgMA.exe --portable --port 8799 --open-browser`로 다른 포트를 지정할 수 있습니다(웹 주소도 `http://127.0.0.1:8799/`로 바뀝니다).

## 배포판 범위와 확인

이 배포판은 빌드 시점의 대시보드·레이아웃 이미지·기준 배치 및 기록을 포함합니다. 브라우저 내부 테트리스/비교 기능은 동작합니다. **새 OpenLane/P&R·아날로그 툴 실행 등 서버 측 EDA 작업은 포함하지 않으며**, 버튼을 누르면 503 안내가 표시됩니다. 실제 물리 설계를 새로 돌리려면 전체 저장소와 WSL/Ubuntu, PDK, OpenLane 등의 별도 설치가 필요합니다. 이 ZIP만으로 signoff 작업을 실행할 수는 없습니다.

최종 GDS 이미지가 보이더라도 DRC/LVS signoff 통과를 뜻하지 않습니다. 웹 서버 상태는 `/api/health`에서 확인할 수 있습니다. 외부 지식 DB가 있다면 `VeriolgMA.exe --portable --port 8788 --knowledge-root "D:\path\to\verilog" --open-browser`처럼 경로를 선택할 수 있습니다.

이 실행 파일은 서명되지 않았습니다. 조직의 보안 정책이 실행을 차단하면 보호 기능을 우회하지 말고 IT 담당자에게 파일 출처와 허용 절차를 확인하세요.
